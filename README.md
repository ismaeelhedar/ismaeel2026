# إلى غالية 🤍

موقع شخصي بصفحة واحدة: حكايتنا، وألبوم صورنا، ولعبة صغيرة، وفي آخرها الهدية.
عربي بالكامل، من اليمين إلى اليسار، ومصمَّم أولًا لشاشة آيفون بعرض 390 بكسل.

---

## English quickstart

```bash
npm install
npm run photos     # optimize photos → WebP variants + blur placeholders
npm run dev        # http://localhost:3000
npm run build      # static export → ./out  (deploy anywhere)
```

Everything editable lives in **`src/content.ts`** — her name, all Arabic copy, chapter
dates, photo filenames and alt text, the memory-game pairs, the gift details and the
closing letter. Drop new photos into `public/photos/`, run `npm run photos`, add one
line to `content.ts`. The design system preview is at **`/style`**.

## التشغيل

```bash
npm install
npm run photos     # تحسين الصور — يجب تشغيله مرة واحدة على الأقل قبل أول بناء
npm run dev        # التطوير على http://localhost:3000
```

| الأمر | ما يفعله |
| --- | --- |
| `npm run dev` | خادم التطوير |
| `npm run photos` | يحوّل الصور إلى WebP بأربعة أحجام ويولّد `src/photos.json` |
| `npm run photos -- --force` | يعيد توليد كل الصور حتى غير المتغيّرة |
| `npm run build` | إخراج ثابت كامل في مجلّد `out/` |
| `npm run typecheck` | فحص الأنواع بلا بناء |
| `npm run lint` | فحص الشيفرة |

> **مهم:** `npm run photos` يجب أن يسبق `npm run build` في أي جهاز جديد، لأن ملف
> `src/photos.json` ونسخ `public/photos/opt/` غير محفوظة في Git.

## كيف أضيف صورة أو أبدّلها

ثلاث خطوات فقط:

1. ضع الملف في `public/photos/` باسم إنجليزي بلا مسافات، مثل `dinner.jpg`
2. شغّل `npm run photos`
3. أضف سطرًا في `src/content.ts` في المكان الذي تريده:

```ts
{ slug: 'dinner', alt: 'وصف الصورة بالعربية', focus: 'top' }
```

- **`slug`** = اسم الملف بدون الامتداد.
- **`alt`** = وصف عربي، تقرأه قارئات الشاشة، وهو مطلوب دائمًا.
- **`focus`** = الجزء الذي يبقى ظاهرًا عند القصّ: `'top'` أو `'center'` أو `'bottom'`.
  استخدم `'top'` إذا كانت الوجوه قريبة من أعلى الصورة.

الأداة تحترم اتجاه EXIF تلقائيًا، فالصور المأخوذة بالهاتف بشكل عمودي لا تنقلب.
وإذا أضفت `slug` لصورة غير موجودة، يظهر مكانها بديل أنيق بلون التوت بدل أيقونة مكسورة.

### أين تُستخدم الصور

| المكان | الحقل في `content.ts` |
| --- | --- |
| فصول الحكاية | `story.chapters[].photos` |
| الألبوم | `gallery.photos` |
| بطاقات اللعبة | `game.pairs` |
| صورة الهدية | `reveal.photo` |
| صورة الرسالة الأخيرة | `letter.photo` |

## كيف أعدّل النصوص

كل كلمة في الموقع موجودة في **`src/content.ts`** — لا نصّ مكتوب داخل المكوّنات إطلاقًا،
بما في ذلك عناوين الأزرار، وتسميات قارئ الشاشة، وعنوان الصفحة، ووصفها، وصفحة الخطأ 404.

أهم الحقول:

```ts
name: 'غالية'                      // يُستخدم داخل الجُمل
opening.displayName: 'غالية حبيبي'  // الاسم الكبير في الافتتاح
opening.lines: [...]               // الأسطر المرتّبة تحت الاسم
reveal.product / color / storage   // تفاصيل الهدية
letter.paragraphs / signature      // الرسالة الأخيرة
```

**قواعد الكتابة المتّبعة:** أرقام غربية (1، 2، 3)، وتواريخ بكلمات عربية
(«ربيع 2024»)، وجُمل قصيرة بلهجة فصيحة مائلة إلى الشامي.

## الهوية البصرية — «التوت البرّي»

افتح **`/style`** في المتصفّح لترى اللوحة كاملة: الألوان، وسُلّم الخطوط، والعناصر.

الألوان معرَّفة مرّة واحدة في `src/app/globals.css` داخل كتلة `@theme`، ويقرأها
Tailwind تلقائيًا (`bg-bb-ink`، `text-bb-frost`، وهكذا).

| المتغيّر | القيمة | الاستخدام |
| --- | --- | --- |
| `--bb-ink` | `#0A0918` | خلفية الصفحة، الأعمق |
| `--bb-midnight` | `#12102B` | خلفية الأقسام |
| `--bb-surface` | `#1C1840` | البطاقات |
| `--bb-surface-2` | `#272052` | مرتفع / عند المرور |
| `--bb-berry` | `#4B3BA8` | اللون الأساسي |
| `--bb-berry-lit` | `#6A56D4` | الأساسي عند التفاعل |
| `--bb-bloom` | `#A99BF2` | مساعد، روابط، حلقات التركيز |
| `--bb-frost` | `#D6CEFF` | الزَغَب — نادر جدًا |
| `--bb-text` | `#F2EFFF` | النص الأساسي |
| `--bb-text-muted` | `#A69FCB` | النص الثانوي |
| `--bb-silver` | `#D9DAE4` | لحظة الكشف فقط |

**قاعدتان تحكمان الإحساس كله:**

- **`--bb-frost`** يظهر ثلاث مرّات في الموقع كله: اسمها في الافتتاح، وقصاصات الكشف،
  وتوقيع الرسالة. لا رابع.
- **`--bb-silver`** لا يظهر إطلاقًا قبل لحظة الكشف. هذا التباين هو المكافأة.

### الخط

**تجوّل (Tajawal)** وحده في كل حرف من الموقع — عناوين ونصًّا وأرقامًا وأزرارًا.
أربعة أوزان: `400` نصّ، `500` تأكيد خفيف، `700` عناوين، `800` العناوين الكبرى.
محفوظ محليًا في `src/app/fonts/` بترخيص OFL (96 كيلوبايت كاملًا) — لا اتصال
بـ Google Fonts ولا بأي شبكة خارجية أثناء التشغيل.

### الحركة

| الطبقة | ما هي | التكلفة |
| --- | --- | --- |
| **الشفق** `Aurora` | أربع كتل ضوئية ضخمة تنجرف خلف الصفحة كلها | CSS، انتقال خالص على كرت الشاشة |
| **ذرّات الضوء** `Motes` | غبار يصعد ببطء في الافتتاح | CSS |
| **كشف الاسم** | تدرّج لوني يعبر الاسم من اليمين إلى اليسار | CSS |
| **كشف الكلمات** `Words` | كل كلمة تطلع من الضباب بدورها | CSS، بلا جافاسكربت |
| **الظهور عند التمرير** `Appear` | صعود + خروج من الضباب | CSS + مراقب تقاطع واحد مشترك |
| **الانزياح** `Parallax` | الصور تتحرّك بسرعات مختلفة | Framer Motion |
| **شريط التقدّم** | خيط رفيع أعلى الصفحة من اليمين | كتابة مباشرة داخل rAF |
| **الأشعّة** | تنفتح من الأعلى في لحظة الكشف وحدها | CSS |

كل ما سبق يتوقّف أو يتحوّل إلى تلاشٍ بسيط مع `prefers-reduced-motion`.

## اللعبة

مطابقة صور من صورنا: **ثلاثة أزواج = ست بطاقات**، قصيرة وسهلة عن قصد.

- لا مؤقّت ولا حدّ للمحاولات ولا حالة خسارة إطلاقًا.
- أي بطاقتين متطابقتين تبقيان مكشوفتين إلى نهاية اللعبة — التقدّم لا يرجع للوراء.
- عند التوقّف أكثر من عشرين ثانية يومض زوج متطابق بهدوء.
- إتمام اللعبة هو ما يفتح **البوّابة**.

**البوّابة** مهمّة: قسم الهدية والرسالة غير موجودين في الصفحة أصلًا قبل الفوز — ليسا
مخفيَّين بـ CSS، بل غير مُركَّبَين. أي أنها لا تستطيع أن تمرّر إصبعها إلى الأسفل
فتحرق المفاجأة على نفسها.

لتغيير عدد البطاقات: أضف أو احذف عناصر من `game.pairs` في `content.ts` — الشبكة تتكيّف وحدها.

## العدّاد وأسباب الحبّ

قسمان إضافيان، كلاهما يُعدَّل من `content.ts` وحده.

**العدّاد** يعدّ منذ تاريخٍ واحد. يُضبط من حقلين معًا:

```ts
since: '2026-04-19T00:00:00+03:00',  // للحساب — صيغة ISO مع المنطقة الزمنية
sinceLabel: '19 نيسان 2026',          // ما يظهر مكتوبًا تحت العدّاد
```

غيّر الاثنين معًا إن غيّرت التاريخ. الساعة `00:00` تقديرية — اضبطها إن أردت أن
تكون خانتا الساعة والدقيقة دقيقتين.

العدّاد يبدأ فارغًا (`—`) ثم يمتلئ فور فتح الصفحة، لأن الصفحة مبنيّة مسبقًا
والوقت على خادم البناء ليس وقتها — وعرض رقمٍ محسوبٍ وقت البناء يعني رقمًا خاطئًا
يقفز أمام عينها.

**أسباب الحبّ:** أضف أو احذف أسطرًا من `reasons.items` — الترقيم يتبع تلقائيًا.

## الموسيقى

صامتة افتراضيًا ولا تعمل أبدًا من تلقاء نفسها. الزرّ في الزاوية السفلية.

- إذا وضعت ملفًا في `public/audio/theme.m4a` فسيُشغَّل هو (عدّل المسار من `audio.src`).
- إذا لم يوجد ملف، يشغّل الموقع **نغمة هادئة مولَّدة داخل المتصفّح**
  (`src/lib/ambient-music.ts`) — سُلّم خماسي دافئ بنغمات عشوائية، فلا تُسمع أي «لفّة»
  متكرّرة. بلا ملفات وبلا حقوق ملكية وبلا شبكة.

## البناء والنشر

```bash
npm run photos && npm run build
```

النتيجة مجلّد `out/` ثابت بالكامل، بلا خادم ولا قاعدة بيانات ولا أي طلب شبكة خارجي.

**استضافة عادية** (Netlify, Cloudflare Pages, GitHub Pages, أو أي استضافة ملفات):
ارفع محتويات `out/` كما هي. لا إعدادات إضافية — `trailingSlash` مفعّل فتعمل الروابط
كمجلّدات.

**Vercel:** اربط المستودع وسيلتقط الإعدادات وحده. أضف `npm run photos` قبل أمر البناء
إن لم تكن ترفع `public/photos/opt/` مع الشيفرة.

> **خصوصية:** الصفحة تحمل `robots: noindex, nofollow`، وبطاقة المعاينة عند مشاركة
> الرابط بلا صورة عن قصد — حتى لا تظهر صوركما في معاينة واتساب أو تيليغرام.

## بنية المشروع

```
src/
├─ content.ts              ← كل النصوص والصور (ابدأ من هنا)
├─ photos.json             ← يولّده npm run photos (لا تعدّله يدويًا)
├─ app/
│  ├─ layout.tsx           lang="ar" dir="rtl" + الخطوط + الوسوم
│  ├─ page.tsx             تركيب الأقسام
│  ├─ not-found.tsx        صفحة 404 بالعربية
│  ├─ globals.css          ألوان الهوية والحركات
│  ├─ fonts/               ملفات تجوّل + ترخيص OFL
│  └─ style/page.tsx       لوحة معاينة الهوية
├─ components/
│  ├─ chrome/              الحُبيبات، التظليل، التوهّج، مفتاح الموسيقى
│  ├─ media/               Photo, PhotoMissing, Lightbox
│  ├─ motion/              غلاف الظهور عند التمرير
│  ├─ sections/            الافتتاح، الحكاية، الألبوم، اللعبة، البوّابة، الكشف، الرسالة
│  └─ ui/                  الأزرار والترويسات
├─ lib/                    المحمّل، قراءة الصور، قفل التمرير، النغمة المولّدة
scripts/optimize-photos.mjs
public/photos/             الأصول + opt/ المولّدة
public/audio/              مكان اختياري لملف الموسيقى
```

**مكوّنات العميل** (`'use client'`) سبعة فقط: مفتاح الموسيقى، وشريط التقدّم، وغلاف
الظهور، والانزياح، وعارض الصور، واللعبة، والبوّابة (ومعها الكشف). كل ما عداها
مكوّنات خادم لا تُرسل أي جافاسكربت — حتى شاشة الافتتاح كاملةً، فكشف الاسم والكلمات
والشفق والذرّات كلها حركات CSS خالصة.

## ملاحظات تقنية

- **الصور:** `next/image` مع **محمّل مخصّص** (`src/lib/image-loader.ts`) بدل
  `unoptimized: true`. السبب: مع `unoptimized` لا يولَّد `srcset` إطلاقًا، فتُحمَّل
  صورة 1600 بكسل حتى للصور المصغّرة. المحمّل المخصّص متوافق تمامًا مع الإخراج الثابت
  لكنه يُبقي `srcset` الحقيقي (240 / 480 / 960 / 1600). عند تغيير هذه الأعرض غيّرها
  في ثلاثة أماكن: `scripts/optimize-photos.mjs` و`next.config.ts` و`image-loader.ts`.
- **بلا قفز في التخطيط:** كل صورة داخل إطار بنسبة أبعاد محسوبة مسبقًا من
  `photos.json`، مع صورة ضبابية صغيرة — أي `CLS ≈ 0`.
- **العربية والحركة:** اسم الافتتاح **لا يُقسَّم إلى حروف منفصلة**، لأن ذلك يكسر اتصال
  الحروف («غ ا ل ي ة»). بدلًا من ذلك يُكشف بتدرّج لوني متحرّك من اليمين إلى اليسار على
  نصّ واحد متّصل.
- **تقليل الحركة:** مع تفعيل `prefers-reduced-motion` تتحوّل كل الحركات إلى تلاشٍ
  بسيط، وتختفي القصاصات، وتبقى البوّابة وكل الوظائف كما هي.
- **الاتجاه:** خصائص CSS منطقية في كل مكان (`padding-inline`، `inset-inline`)،
  والأسهم معكوسة، والسحب في عارض الصور بالاتجاه العربي الصحيح، وكذلك مفتاحا
  الأسهم على لوحة المفاتيح.
- **الأصول:** ملفات `public/photos/*.jpg` الأصلية تُنسخ إلى `out/` مع أنها لا تُطلب
  أبدًا. إن أزعجك حجم النشر، انقل الأصول خارج `public/` وعدّل `SOURCE_DIR` في
  سكربت التحسين.
